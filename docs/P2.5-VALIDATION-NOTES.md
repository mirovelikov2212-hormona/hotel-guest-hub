## Certification semantics

The certification RPC is idempotent and exact-lineage gated. It requires explicit evidence for generic Staff runtime, tenant isolation, Preview build, runtime errors, Supabase security, integration placeholder readiness, reporting fail-closed state, branding placeholder state, and knowledge placeholder state.

A successful future certification transaction may activate/certify only the linked Sandbox hotel. Before commit it asserts that the linked Production hotel remains inactive, its public identity remains reserved, and its health/certification state remains pending/not_started. Production publication is a separate future audited stage.
